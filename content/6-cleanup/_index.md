#### Clean up resources

1. Deleting **lifecycle policy**

   - Select the policy.
   - Select **Actions**.
   - Select **Delete lifecycle policy**.

![Clean up resource](/images/5/0001.png?featherlight=false&width=90pc)

2. Confirm deletion.

![Clean up resource](/images/5/0002.png?featherlight=false&width=90pc)

3. Choose to delete snapshots.

   - Select snapshots related to the lab.
   - Select **Actions**.
   - Select **Delete snapshot**.

![Clean up resource](/images/5/0003.png?featherlight=false&width=90pc)

4. Confirm deletion.

![Clean up resource](/images/5/0004.png?featherlight=false&width=90pc)

6. Implement **Terminate** EC2 instance.

   - Select **EC2** instance.
   - Select **Instance state**.
   - Select **Terminate instance**.

![Clean up resource](/images/5/0005.png?featherlight=false&width=90pc)
